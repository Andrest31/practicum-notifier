
# Practicum Notifier

Telegram-уведомления об открытии заданий первого семестра программы «Аналитика данных» Яндекс Практикума.

## Возможности

- Автоматическая проверка доступности заданий каждые 20 минут.
- Отслеживание перехода заданий из закрытого состояния в открытое.
- Уведомления в Telegram с названием дисциплины, заданием, типом работы и ссылкой.
- Сохранение статусов в SQLite без повторной отправки уведомлений.
- Защита от неполной загрузки данных и параллельных запусков.
- Уведомления о повторяющихся ошибках и восстановлении работы.

## Технологии

Python, Playwright, SQLite, Telegram Bot API, uv, macOS launchd.

## Запуск

Установить зависимости:

```bash
uv sync
uv run playwright install chromium
```

Создать `.env` с параметрами:

```env
BOT_TOKEN=your_bot_token
CHAT_ID=your_chat_id
```

Выполнить первую авторизацию в Практикуме через браузер Playwright.

Запустить проверку:

```bash
uv run python check.py
```

Для автоматической проверки используется macOS launchd с интервалом 20 минут.

## Примечание

Бот работает с авторизованной сессией пользователя. Для автоматических проверок компьютер должен быть включён, а пользовательская сессия macOS — активна.
